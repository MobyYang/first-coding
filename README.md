# first-coding · 天平学方程

my first coding, hello world!

**天平学方程**是一个给小朋友用的学习网页：用天平一步一步学会**二元一次方程组**。
每架平衡的天平就是一个方程，每种水果就是一个未知数；第 6 课把水果换成 x 和 y，孩子会看到自己一直在解真正的方程组。
默认中文，也可以切换成 English；平板、电脑、手机都能用。

完整的方案见 [docs/proposal.md](docs/proposal.md)。

## 怎么学

一共 7 节课，每节课分两部分：

1. **例题**：页面上写明“这是例题，跟着我一步一步学”。每一步写成：第几步、做什么、一句为什么，再把数字步骤一行一行写出来（比如“2🍎 + 3 − 3 = 11 − 3”，两个算式相加、相减用竖式）。这一步的天平就画在这一步里，跟着变；前面的步骤一直留着。每翻一页，猫头鹰老师把这一页**读出来**（可以“🔊 再听一遍”）。
2. **练习**：5 道同类的题，**孩子自己列步骤**。每一步先想做什么，选一个学过的方法（两边同时 ÷、两边同时 −、代入、两式相减、两式相加），点天平、写数，点“写出来”。这一步不能这样做时只说为什么；能做就写出算式，结果由孩子自己算。算对了打勾，天平跟着变，再列下一步。可以“擦掉一步”换个方法。
   不会做可以点“提示”：第一次问下一步怎么想，第二次说用哪个方法；也可以“看例题”。提示、为什么不能这样做、算错了、做对了，老师也会读出来。

**题库（多练）**：课程表上点“📚 题库”，每一课都能直接做题，不用先看例题；做完一道点“下一题”，一直有新题，想停就停。每一课记着练了几题、几题一次做对（只存在这台设备上）。

**第 4 课先试用“看图算”**：不写方程，看着天平想。只有两个动作——⚖️ 比一比（两架天平一样的划掉，多出来的东西重多少，右边就多多少）、🔄 换一换（知道一样，换进天平，求另一样）。每一步一句问话、一道普通算术，孩子只填一个数：
```
第 1 步  ⚖️ 比一比：B 比 A 多 1 个 🍎    多出来的 1 个 🍎 有多重？ 14 − 10 = 4，所以 🍎 = 4
第 2 步  🔄 换一换：A 里的 🍎 换成 4      🍌 有多重？ 10 − 4 = 6，所以 🍌 = 6
```
孩子用着好，再把第 3、5 课也改成这样。

| 课 | 学什么 | 课本里的名字 |
|---|---|---|
| 1 | 平均分 | 等式两边同除以一个数 |
| 2 | 两边同时拿走 | 等式两边同减一个数 |
| 3 | 先求一个，再代入 | 代入消元法 |
| 4 | 比一比，换一换（看图算，试用） | 加减消元法 |
| 5 | 两式相加 | 加减消元法 |
| 6 | 用字母写方程组 | 二元一次方程组 |
| 7 | 买东西 | 应用题 |

## 自己运行

需要先装 [Node.js](https://nodejs.org/)（22 或更新版本）。

```bash
npm install      # 第一次运行前安装依赖
npm run dev      # 本地预览，浏览器打开终端里显示的地址
npm test         # 运行出题、解题、演算和老师讲解的自动测试
npm run build    # 打包成一个独立的 dist/index.html，双击就能打开
```

## 老师讲解的声音（豆包语音）

讲解的声音用[豆包语音合成大模型](https://www.volcengine.com/docs/6561/1598757)提前录成 mp3，网页只放录好的文件，**API Key 不会进网页**（网页是公开的，key 放进去会被别人拿去用）。

1. 在火山引擎控制台开通豆包语音，拿到 API Key。
2. 把 key 放进环境变量 `DOUBAO_API_KEY`，或者照着 `.env.example` 写一个 `.env` 文件（`.env` 不会提交）。**不要**把 key 写进代码。
3. 运行：
   ```bash
   npm run voice              # 把 7 课例题的讲解和几句固定的话录成 public/voice/*.mp3，写 src/voice-manifest.json
   npm run voice -- --list    # 只看要录哪些话，不需要 key
   npm run build              # 重新打包，网页就会用这些录音
   ```
   已经录好的不会重录；改了讲解的文字，再运行一次就只录改了的那几段。
4. 把 `public/voice/` 和 `src/voice-manifest.json` 提交上去。

可选：`DOUBAO_VOICE` 换音色（默认 `zh_female_xiaohe_uranus_bigtts` 小何 2.0），`DOUBAO_SPEECH_RATE` 调语速（-50 到 100，默认 -10，慢一点）。
自己复刻的音色（`S_` 开头）会自动用 `seed-icl-2.0`。用旧版控制台的 App ID 和 Access Token 也可以：放进 `DOUBAO_APP_ID` 和 `DOUBAO_ACCESS_TOKEN`。

没有录音的话（提示里的数每次都不一样，或者还没运行 `npm run voice`），用这台设备自带的声音朗读。英文界面也用设备自带的英文声音。
右上角的 🔊 和设置里的“老师讲解”可以关掉声音。

├── core/              纯逻辑，不依赖界面，全部有单元测试

│   ├── solver.js      解题程序：按顺序找下一步
│   ├── explain.js     把解题过程变成一步一步
│   ├── working.js     例题的演算：每一步的标题、数字步骤和竖式
│   ├── practice.js    孩子自己列步骤：检查这一步能不能做、写出算式、下一步的提示
│   ├── look.js        看图算（第 4 课）：比一比、换一换，每一步一道普通算术；例题和练习都用它
│   ├── styles.js      这一课用哪种写法（列算式 / 看图算）
│   ├── tokens.js      演算里的记号（数、东西、+ − × ÷ =）
│   ├── generator.js   出题：先定答案再出题，保证答案是整数；题库一道接一道出新题
│   ├── lessons.js     7 节课的配置和例题
│   └── random.js      可重复的随机数
├── components/
│   ├── HomeView.vue   课程表
│   ├── BankView.vue   题库：每一课都能一直做新题

│   ├── StepComposer.vue 列一步：选方法、点天平、写数、写出来

│   ├── WorkSheet.vue  演算纸：题目和一步一步（WorkTokens 画一行算式，ColumnBlock 画竖式）

├── i18n.js            中英文文字

└── store.js           学习记录（只存在本机浏览器里）
public/voice/          老师讲解的录音（npm run voice 生成）
scripts/make-voice.mjs 用豆包语音录老师讲解
tests/                 engine.test.js（出题、解题、演算）、voice.test.js（讲解说的话、录音）
