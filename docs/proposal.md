| 项目 | 内容 |

| 名称 | **方程小侦探** / Equation Detective |

## 二、教学设计

### 2.1 核心比喻：每架平衡的天平就是一个方程

- 每种水果是一个未知数，每架**平衡**的天平是一条线索（一个方程）。
- 只有一条线索时答案有很多种；两条线索才能“破案”。孩子由此明白为什么方程组要两个方程。
- 按“实物 → 图形 → 符号”循序渐进：天平上的水果 → 天平下面的算式（如 2🍎 + 🍌 = 13）→ 第 5 章的 2x + y = 13。

### 2.2 四个侦探道具 = 课本里的四种方法

| 道具 | 孩子看到的 | 对应的数学方法 |
|---|---|---|
| ✂️ 分一分 | 左边能平均分成几份，两边一起分 | 等式两边同除以一个数 |
| ✋ 拿走 | 左边有砝码，两边同时拿走一样重的 | 等式两边同减一个数 |
| 🔄 换一换 | 一样重的东西可以互相替换 | 代入消元 |
| ➕ 合一合 | 两架平衡的天平放在一起，还是平衡 | 加减消元（两个方程相加） |

每用一次道具，两边都会飘出同样的“÷ 3”或“− 5”，天平晃一晃再停稳，强化“两边一起变，天平不会歪”。
道具只在能用的时候出现，不会做出错误的变形。

### 2.3 另一条路：猜一猜、称一称

孩子也可以直接在“侦探笔记”里填数字，再点“称一称”。天平会按孩子猜的重量倾斜，往下沉的一边就是太重了，同时显示“12 > 10”。这就是“检验”：把答案代回每个方程看成不成立。

### 2.4 提示和教学

- **提示**：第一次点，猫头鹰“咕咕探长”说出下一步该用哪个道具，并让对应的按钮闪烁；再点一次，它就帮孩子做这一步。
- **手把手教学**：每关第一题会自动一步步引导，不扣星。
- **星星**：称错一次或用一次提示扣 1 分；扣分 ≤ 1 得 3 颗星，≤ 4 得 2 颗星，其余 1 颗星。每关完成得一张动物贴纸，3 颗星是金边贴纸。

## 三、关卡（5 章 13 关，已实现）

| 章 | 关卡 | 学什么 | 例题 |
|---|---|---|---|
| 1 天平训练营 | 1-1 平均分 | 分一分 | 5🍎 = 20 |
| | 1-2 拿走一样多 | 拿走 | 🍎 + 5 = 9 |
| | 1-3 两步破案 | 先拿走再分 | 2🍎 + 3 = 11 |
| 2 水果谜题 | 2-1 先破简单的 | 先解只有一种水果的天平，再换进去（代入） | 3🍎 = 12，🍎 + 2🍌 = 14 |
| | 2-2 换一换 | 一次换掉好几个 | 2🍎 = 8，2🍎 + 🍌 = 13 |
| | 2-3 连环谜题 | 三种水果，一个接一个 | 3🍋 = 24，🍋 + 2🍓 = 14，🍓 + 2🍎 = 21 |
| 3 比一比 | 3-1 打包替换 | 大天平里藏着一整套小天平 | 🍉 + 🍌 = 10，2🍉 + 🍌 = 12 |
| | 3-2 多换几次 | 连续换两次 | 🍌 + 🍉 = 8，🍌 + 3🍉 = 18 |
| | 3-3 合一合 | 谁也装不下谁，先合再分（加减消元） | 2🍐 + 🍇 = 13，🍐 + 2🍇 = 14 |
| 4 故事侦探 | 4-1 鸡兔同笼 | 头和脚两条线索；“假设全是鸡”的古法 | 7 个头、18 只脚 |
| | 4-2 小卖部 | 价格问题 | 🍩 + 2🧁 = 22 元，🍩 + 🧁 = 15 元 |
| 5 字母登场 | 5-1 代号 x 和 y | 水果换成 x、y，道具下面标出数学名称 | 2x + 3y = 34，3x = 24 |
| | 5-2 方程组大挑战 | 所有道具综合运用 | 2x + y = 14，x + 2y = 16 |

每道题破案后，都会把原来的线索写成方程组（带大括号）和答案，帮孩子把图形和算式对上号。

## 四、题目怎么出：先定答案，再出题

1. 先随机定好每样东西的重量（2–9 之间、互不相同的整数）。
2. 按本关的模板摆出天平，右边的数由答案算出来，保证答案一定是整数。
3. 用内置的“解题思路”走一遍，确认只用本关的道具就能解开；需要合一合的关卡，确认确实用得上。
4. 同一关内不出重复的题，每次进关都随机出新题。

自动测试（`npm test`）会为每一关生成几百道题（一共约 7,000 道），检查：答案是唯一的正整数、右边的数不超过 60、本关道具一定能解开；还会随机乱按道具，确认提示仍然能带孩子走到答案。

## 五、技术方案

| 层面 | 选择 |
|---|---|
| 框架 | Vue 3 + Vite，打包成**一个独立的 HTML 文件**（约 210 KB），双击就能玩 |
| 图形 | 手画的 SVG 天平，弹簧物理动画；猫头鹰也是 SVG |
| 音效 | Web Audio 现场合成，不需要音频文件 |
| 字体 | 数字和字母用内嵌的 Fredoka（圆润好认），中文用系统字体；不依赖外网字体，国内也能正常显示 |
| 进度 | 保存在本机浏览器（localStorage），读写失败也不影响游戏 |
| 测试 | Vitest，覆盖天平模型、道具、解题思路、出题器、鸡兔同笼 |
| 部署 | GitHub Pages（GitHub Actions 自动发布） |

目录结构见 [README](../README.md)。

## 六、儿童友好与隐私

- 大按钮（≥ 44px）、大字号，屏幕数字键盘不会挡住题目
- 对错同时用颜色和 ✓ / 符号表示；系统开启“减少动态效果”时关闭动画和彩带
- 声音可以关；无广告、无外部链接
- 不需要注册，不收集任何个人信息
