## 一、一句话说明

给 IB 四年级（9–10 岁）的孩子学**二元一次方程组**。用天平来讲：**每架平衡的天平就是一个方程，每种水果就是一个未知数**。一共 7 节课，每节课只学一个新方法。每道题都一步一步**演算**出来：先看老师演算例题，再照着例题自己演算。

| 项目 | 内容 |
|---|---|
| 名称 | 天平学方程 |
| 学生 | 9–10 岁，IB PYP 四年级；也适合刚接触方程的小学高年级学生 |
| 学完能做什么 | 会一步一步解两个未知数的方程组（代入、两式相减、两式相加），能看懂用 x、y 写的方程组 |
| 每次用多久 | 一节课 10–15 分钟 |
| 设备 | 平板、电脑或手机的浏览器；不用下载，不用登录 |
| 语言 | 默认中文，设置里可以换成 English |

## 二、演算纸：讲解和练习用的是同一种写法

屏幕上一边是天平，一边是演算纸（手机上天平在上、演算纸在下）。演算纸先写题目里的算式，再一步一步往下写。每一步两行：

- 第一行是**做什么**，一句很短的话，比如“A：两边同时 − 3”“把 🍎 = 5 代入 B”“B 比 A 多 1 个 🍎”“把 A 和 B 加起来”；
- 第二行是**做完以后的新算式**，把算的过程也写出来，比如“2🍎 = 11 − 3 = 8”。

前面的步骤一直留在纸上，孩子能看到每一步是从哪一行来的。每写一步，对应的天平也跟着变：两边同时飘出“− 3”，晃一晃再停稳，说明两边做了同样的事，天平还是平的。

例：第 3 课的例题（2🍎 = 10，🍎 + 🍌 = 8）

```
A  2🍎 = 10
B  🍎 + 🍌 = 8
   ↓ A：两边同时 ÷ 2
A  🍎 = 10 ÷ 2 = 5
   ↓ 把 🍎 = 5 代入 B
B  5 + 🍌 = 8
   ↓ B：两边同时 − 5
B  🍌 = 8 − 5 = 3
答：🍎 = 5，🍌 = 3
检查：A 2 × 5 = 10 ✓   B 5 + 3 = 8 ✓
```

## 三、每节课怎么上

### 1. 讲解（教）

1. 猫头鹰老师先用一两句话说这节课的方法，比如第 2 课：“两边同时减去同一个数，天平还是平的。先减去砝码，再除以个数。”
2. 老师演算一道例题。孩子每点一次“下一步”，演算纸上多写一步，天平跟着变。算出来的数用绿色标出，就是练习时要孩子自己填的那些数。
3. 最后写出答案，再把答案放回每架天平检查一遍。
4. 可以点“上一步”回看，也可以“再看一遍”；看懂了点“开始练习”。

### 2. 练习（学）

- 一共 5 道题，和例题是同一类题，每次都是新出的题。
- 孩子照着例题，在演算纸上一步一步做。每一步“做什么”和新算式的格式都已经写好，要算的数空着：
  ```
  A  2🍎 + 5 = 17
     ↓ A：两边同时 − ☐        ← 孩子想：要减去几？填 5
  A  2🍎 = 17 − 5 = ☐         ← 孩子算：填 12
     ↓ A：两边同时 ÷ ☐        ← 填 2
  A  🍎 = 12 ÷ 2 = ☐          ← 填 6，这就是答案
  ```
- 点一个空，用屏幕上的数字键盘填，键盘上方会显示正在填的那一行。填对了空变绿，接着填下一个；这一步都填对了，天平才跟着变，再写下一步。
- **填错了**：这个空变红，不告诉正确的数，让孩子再算一次。
- **不会做**：孩子可以自己选下面两种帮助，只有点了才出现，不会自己弹出来。
  - 💡 **提示**：只说正在填的这一个空怎么想，不给答案。比如“天平 A 左边有几个 🍎？”“12 ÷ 3 = ?　想一想：3 × ? = 12”“先写多的那架：天平 B 的右边是多少？”
  - 📖 **看例题**：打开老师写好的例题演算，照着做。
- **成绩**：“5 道题里，一次做对几道”。没有填错、没看提示，才算一次做对。5 道都一次做对得 3 颗星，3–4 道得 2 颗星，其余 1 颗星。之后可以“再练一次”（换一组新题），或者进入下一课。

## 四、7 节课

| 课 | 学什么 | 例题 | 演算里的关键一步 | 课本里的名字 |
|---|---|---|---|---|
| 1 平均分 | 几个一样的东西一共多重，1 个有多重 | 3🍎 = 12 | A：两边同时 ÷ 3 → 🍎 = 12 ÷ 3 = 4 | 等式两边同除以一个数 |
| 2 两边同时拿走 | 左边还有砝码时，先把它拿走 | 2🍎 + 3 = 11 | A：两边同时 − 3 → 2🍎 = 11 − 3 = 8 | 等式两边同减一个数 |
| 3 先求一个，再代入 | 两种水果，先算出一种 | 2🍎 = 10，🍎 + 🍌 = 8 | 把 🍎 = 5 代入 B → 5 + 🍌 = 8 | 代入消元法 |
| 4 两式相减 | 两架天平比一比 | 🍎 + 🍌 = 10，2🍎 + 🍌 = 14 | B 比 A 多 1 个 🍎 → 🍎 = 14 − 10 = 4 | 加减消元法（两式相减） |
| 5 两式相加 | 没法直接比时，把两架合起来 | 2🍎 + 🍌 = 13，🍎 + 2🍌 = 14 | 把 A 和 B 加起来 → 3🍎 + 3🍌 = 13 + 14 = 27 | 加减消元法（两式相加） |
| 6 用字母写方程组 | 把水果换成 x 和 y | x + y = 10，2x + y = 14 | 和前面一样，只是写成字母 | 二元一次方程组 |
| 7 买东西 | 用方程组算价钱 | 🍦 + 🧃 = 8 元，2🍦 + 🧃 = 13 元 | B 比 A 多 1 个 🍦 → 🍦 = 13 − 8 = 5 | 应用题 |

第 6 课的练习把前面几种题混在一起；第 7 课的练习是第 3、4 课的题型，换成了买东西。

**举例：第 5 课例题的完整演算**

```
A  2🍎 + 🍌 = 13
B  🍎 + 2🍌 = 14
   ↓ 把 A 和 B 加起来
C  3🍎 + 3🍌 = 13 + 14 = 27
   ↓ C：两边同时 ÷ 3
C  🍎 + 🍌 = 27 ÷ 3 = 9
   ↓ A 比 C 多 1 个 🍎
A  🍎 = 13 − 9 = 4
   ↓ 把 🍎 = 4 代入 C
C  4 + 🍌 = 9
   ↓ C：两边同时 − 4
C  🍌 = 9 − 4 = 5
答：🍎 = 4，🍌 = 5
```

可以看到，后面的课用的都是前面学过的方法（平均分、拿走、比一比、代入），每节课只多学一个新东西。

## 五、为什么这样教

- **看得到前后关系**：演算一步一步写在同一张纸上，前面的步骤不会消失，孩子能看出每一步是从哪一行来的，形成完整的思路。
- **字少**：每一步只写一句“做什么”和一行算式，道理由猫头鹰老师在开头用一两句话讲。
- **先看，再照着做**：练习的格式和例题一模一样，孩子照着老师的方法一步一步做，每个数都自己算。
- **从实物到符号**：天平上的水果 → 演算纸上的算式（2🍎 + 🍌 = 13）→ 第 6 课的 2x + y = 13。
- **错在哪一步，马上知道**：每个空填完就知道对不对，错了不给答案，让孩子自己再算。
- **帮助由孩子自己选**：提示只说正在填的这个空怎么想，不会自己弹出来。

## 六、题目怎么出

1. 先定答案：每样东西的重量是 2–9 的整数，两样东西不一样重。
2. 按本课的题型摆出天平，右边的数由答案算出来，所以答案一定是整数；右边的数不超过 60。
3. 用程序按本课的方法把题解一遍，生成这道题的演算过程和要孩子填的空。
4. 同一组的 5 道题不重复，每次进来都是新题。

自动测试（`npm test`）会检查每课的例题和 100 组随机题：演算里的每一行，把答案代进去都成立；每一步都有要孩子填的空，而且都是两位数以内的正整数；一步一步做下来，能算出全部答案。

## 七、和前面的版本相比，去掉了什么

- 侦探主题、案件和剧情；关卡地图和贴纸本。
- “分一分”“拿走”“换进来”“合起来”这些按钮。这些方法现在写在演算里，由老师演示，孩子照着做。
- 整段的长句讲解、一步一页看不到前面的讲解方式。
- 只填最后答案的答案栏，以及“答错了天平会歪”的称一称。现在每一步都要演算，错在哪个空就在哪个空上改。
- 自动弹出的提示。
- 鸡兔同笼一关（以后可以作为应用题再加回来）。

## 八、技术

| 项目 | 做法 |
|---|---|
| 框架 | Vue 3 + Vite，打包成一个独立的 HTML 文件（约 200 KB），双击也能打开 |
| 图形 | 手画的 SVG 天平，每变一步晃一晃再停稳；猫头鹰老师也是 SVG |
| 声音 | 用 Web Audio 现场合成，不需要音频文件，可以关掉 |
| 字体 | 数字和字母用内嵌的 Fredoka，中文用系统字体，不依赖外网 |
| 学习记录 | 只存在这台设备的浏览器里（localStorage），读写失败也不影响使用 |
| 测试 | Vitest：天平模型、解题程序、出题、讲解步骤、演算过程 |
| 发布 | 现在是 claude.ai 上的网页，打开链接就能用；以后可以合并到 `main`，自动发布到 GitHub Pages |

## 九、儿童友好与隐私

- 大按钮、大字号；用屏幕上的数字键盘填数，键盘上方显示正在填的那一行
- 对错同时用颜色和 ✓ 表示；系统开启“减少动态效果”时关闭动画
- 设置里有给家长的说明：每一课对应课本里的哪种方法
- 无广告、无外部链接；不用注册，不收集任何个人信息

## 十、以后可以加

- 根据孩子用下来的情况调整难度
- 自己做：不给“做什么”，让孩子自己选这一步用哪个方法
- 错题再练一次
- 更多应用题：鸡兔同笼、年龄、分东西
- 讲解配上语音
- 画图法：两条直线的交点就是答案
