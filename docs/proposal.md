## 一、一句话说明

给 IB 四年级（9–10 岁）的孩子学**二元一次方程组**。用天平来讲：**每架平衡的天平就是一个方程，每种水果就是一个未知数**。一共 7 节课，每节课只学一个新方法。每道题都一步一步**演算**出来：先跟老师学例题，再照着例题自己演算。

| 项目 | 内容 |
|---|---|
| 名称 | 天平学方程 |
| 学生 | 9–10 岁，IB PYP 四年级；也适合刚接触方程的小学高年级学生 |
| 学完能做什么 | 会一步一步解两个未知数的方程组（代入、两式相减、两式相加），能看懂用 x、y 写的方程组 |
| 每次用多久 | 一节课 10–15 分钟 |
| 设备 | 平板、电脑或手机的浏览器；不用下载，不用登录 |
| 语言 | 默认中文，设置里可以换成 English |

## 二、演算纸：例题和练习用的是同一种写法

演算纸先写**题目**：每架天平的图和它的算式。然后一步一步往下写，前面的步骤一直留在纸上，孩子能看到每一步是从哪一行来的。每一步有四样东西：

1. **第几步 + 做什么**：比如“第 3 步　A 减去 C”；
2. **为什么**：一句话讲道理（例题里写，练习时不写）；
3. **这一步的天平**：就画在这一步里，先是变之前，再变成变之后，两边飘出这一步做的事（比如左边“− (🍎 + 🍌)”、右边“− 9”），点一下可以再看一次；
4. **数字步骤**：把算的过程一行一行写出来。

| 这一步做什么 | 数字步骤怎么写 |
|---|---|
| 两边同时 ÷ | 3🍎 ÷ 3 = 12 ÷ 3 → 🍎 = 4 |
| 两边同时 − | 2🍎 + 3 − 3 = 11 − 3 → 2🍎 = 8 |
| 代入 | 🍎 + 🍌 = 9 → 4 + 🍌 = 9（换掉的东西写在原来的位置上） |
| 两式相加、相减 | 竖式，上下对齐：左边加（减）左边，右边加（减）右边 |
| 把几份换掉 | 3x + 2y = 22 → x + (x + y) + (x + y) = 22 → x + 9 + 9 = 22 |

例：第 5 课的例题（A：2🍎 + 🍌 = 13，B：🍎 + 2🍌 = 14）

```
第 1 步  把 A 和 B 加起来
         两架平的天平放在一起，还是平的。上下对齐，左边加左边，右边加右边。
       A   2🍎 +  🍌 = 13
    +  B    🍎 + 2🍌 = 14
       ─────────────────
       C   3🍎 + 3🍌 = 27

第 2 步  C 的两边同时 ÷ 3
         C 的左边正好是 3 份（🍎 + 🍌）。两边同时平均分成 3 份，天平还是平的。
       C   (3🍎 + 3🍌) ÷ 3 = 27 ÷ 3
       C   🍎 + 🍌 = 9

第 3 步  A 减去 C
         A 和 C 都有 🍎 和 🍌，A 还多 1 个 🍎。上下对齐，左边减左边，右边减右边：
         一样的东西减掉了，剩下多出来的 1 个 🍎。
       A   2🍎 + 🍌 = 13
    −  C    🍎 + 🍌 = 9          （上下的 🍌 一样多，划掉）
       ─────────────────
       A    🍎      = 4

第 4 步  把 🍎 = 4 代入 C
         已经算出 🍎 = 4。把 C 里的 🍎 换成 4，天平还是平的。
       C   🍎 + 🍌 = 9
       C   4 + 🍌 = 9

第 5 步  C 的两边同时 − 4
         C 的左边除了 🍌，还有 4。两边同时拿走 4，天平还是平的。
       C   4 + 🍌 − 4 = 9 − 4
       C   🍌 = 5

答：🍎 = 4，🍌 = 5
检查：A 2 × 4 + 5 = 13 ✓　B 4 + 2 × 5 = 14 ✓
```

## 三、每节课怎么上

### 1. 例题（教）

1. 页面最上面写着：“📖 这是例题，跟着我一步一步学”，下面一句话讲这节课的方法。比如第 4 课：“两个算式相减：左边减左边，右边减右边。一样的东西减掉了，剩下的就是多出来的。”
2. 先看题目，再点“下一步”，一步一步往下看。每一步都按上面的四样东西写出来，天平就在这一步里变。
3. 算出来的数标成绿色，练习时孩子要自己填的就是这些数。
4. 最后写出答案，再把答案放回每架天平检查一遍。可以点“上一步”回看，也可以“再看一遍”；看懂了点“开始练习”。

### 2. 练习（学）

- 一共 5 道题，和例题是同一类题，每次都是新出的题。页面最上面写着“✏️ 练习 1 / 5：照着例题，自己一步一步算”。
- 每一步的标题和数字步骤的格式都写好了，要算的数空着：
  ```
  第 1 步  A 的两边同时 − ☐           ← 孩子想：要减去几？填 5
         A  2🍎 + 5 − 5 = 17 − 5
         A  2🍎 = ☐                  ← 孩子算：填 12
  第 2 步  A 的两边同时 ÷ ☐           ← 填 2
         A  2🍎 ÷ 2 = 12 ÷ 2
         A  🍎 = ☐                   ← 填 6，这就是答案
  ```
- 点一个空，用屏幕上的数字键盘填，键盘上方会显示正在填的那一行。填对了空变绿，接着填下一个。
- 一步里的空都填对了：这一步打勾、变绿，这一步的天平跟着变，停一会儿再出下一步。
- **填错了**：这个空变红，这一步里写着“不对，再算一算”，不告诉正确的数。
- **不会做**：孩子可以自己选下面两种帮助，只有点了才出现，不会自己弹出来。
  - 💡 **提示**：写在这一步里，只说正在填的这个空怎么想，不给答案。比如“天平 A 左边有几个 🍎？”“12 ÷ 3 = ?　想一想：3 × ? = 12”。
  - 📖 **看例题**：打开例题的完整演算，每一步都写着为什么，照着做。
- **成绩**：“5 道题里，一次做对几道”。没有填错、没看提示，才算一次做对。5 道都一次做对得 3 颗星，3–4 道得 2 颗星，其余 1 颗星。

## 四、7 节课

| 课 | 学什么 | 例题 | 关键的一步 | 课本里的名字 |
|---|---|---|---|---|
| 1 平均分 | 几个一样的东西一共多重，1 个有多重 | 3🍎 = 12 | A 的两边同时 ÷ 3：3🍎 ÷ 3 = 12 ÷ 3 | 等式两边同除以一个数 |
| 2 两边同时拿走 | 左边还有砝码时，先把它拿走 | 2🍎 + 3 = 11 | A 的两边同时 − 3：2🍎 + 3 − 3 = 11 − 3 | 等式两边同减一个数 |
| 3 先求一个，再代入 | 两种水果，先算出一种 | 2🍎 = 10，🍎 + 🍌 = 8 | 把 🍎 = 5 代入 B：5 + 🍌 = 8 | 代入消元法 |
| 4 两式相减 | 两个算式相减 | 🍎 + 🍌 = 10，2🍎 + 🍌 = 14 | B 减去 A（竖式）：🍎 = 4 | 加减消元法（两式相减） |
| 5 两式相加 | 两个算式相加 | 2🍎 + 🍌 = 13，🍎 + 2🍌 = 14 | 把 A 和 B 加起来（竖式）：3🍎 + 3🍌 = 27 | 加减消元法（两式相加） |
| 6 用字母写方程组 | 把水果换成 x 和 y | x + y = 10，2x + y = 14 | 和前面一样，只是写成字母 | 二元一次方程组 |
| 7 买东西 | 用方程组算价钱 | 🍦 + 🧃 = 8 元，2🍦 + 🧃 = 13 元 | B 减去 A（竖式）：🍦 = 5 | 应用题 |

第 6 课的练习把前面几种题混在一起；第 7 课的练习是第 3、4 课的题型，换成了买东西。后面的课用的都是前面学过的方法，每节课只多学一个新东西。

## 五、为什么这样教

- **每一步都能推出下一步**：两边做了什么写成算式，相加、相减用竖式对齐，一样的东西划掉，孩子能看清新算式是怎么来的。
- **看得到前后关系**：前面的步骤一直留在同一张纸上，从题目一路写到答案。
- **图就在旁边**：天平画在正在看的这一步里，看算式的时候就能看到天平怎么变。
- **先学，再照着做**：例题写明“这是例题”，每一步说清楚为什么；练习的格式和例题一模一样，每个数都由孩子自己算。
- **从实物到符号**：天平上的水果 → 演算纸上的算式（2🍎 + 🍌 = 13）→ 第 6 课的 2x + y = 13。
- **错在哪一步，马上知道**：每个空填完就知道对不对，错了不给答案，让孩子自己再算。

## 六、题目怎么出

1. 先定答案：每样东西的重量是 2–9 的整数，两样东西不一样重。
2. 按本课的题型摆出天平，右边的数由答案算出来，所以答案一定是整数；右边的数不超过 60。
3. 用程序按本课的方法把题解一遍，生成这道题的每一步：标题、数字步骤、要孩子填的空和这一步的天平。
4. 同一组的 5 道题不重复，每次进来都是新题。

自动测试（`npm test`）会检查每课的例题和 100 组随机题：
- 每一行算式，把答案代进去都成立；
- 竖式里左边加（减）左边、右边加（减）右边都算对了；
- 每一步都有要孩子填的空，而且都是两位数以内的正整数；
- 一步一步做下来，能算出全部答案。

## 七、和前面的版本相比，去掉了什么

- 侦探主题、案件和剧情；关卡地图和贴纸本。
- “分一分”“拿走”“换进来”“合起来”这些按钮。这些方法现在写在演算里，由老师演示，孩子照着做。
- 整段的长句讲解；一步一页、看不到前面步骤的讲解方式。
- 只写结果、推不出下一步的步骤（比如只写“A 比 C 多 1 个 🍎 → 🍎 = 4”）。
- 放在左边、看算式时看不到的大天平。
- 只填最后答案的答案栏，以及“答错了天平会歪”的称一称。
- 自动弹出的提示。
- 鸡兔同笼一关（以后可以作为应用题再加回来）。

## 八、技术

| 项目 | 做法 |
|---|---|
| 框架 | Vue 3 + Vite，打包成一个独立的 HTML 文件（约 200 KB），双击也能打开 |
| 图形 | 手画的 SVG 天平，每一步变化时晃一晃再停稳；猫头鹰老师也是 SVG |
| 声音 | 用 Web Audio 现场合成，不需要音频文件，可以关掉 |
| 字体 | 数字和字母用内嵌的 Fredoka，中文用系统字体，不依赖外网 |
| 学习记录 | 只存在这台设备的浏览器里（localStorage），读写失败也不影响使用 |
| 测试 | Vitest：天平模型、解题程序、出题、讲解步骤、演算过程 |
| 发布 | 现在是 claude.ai 上的网页，打开链接就能用；以后可以合并到 `main`，自动发布到 GitHub Pages |

## 九、儿童友好与隐私

- 大按钮、大字号；用屏幕上的数字键盘填数，键盘上方显示正在填的那一行
- 对错同时用颜色和 ✓ 表示；系统开启“减少动态效果”时关闭动画
- 设置里有给家长的说明：每一课对应课本里的哪种方法
- 无广告、无外部链接；不用注册，不收集任何个人信息

## 十、以后可以加

- 根据孩子用下来的情况调整难度
- 自己做：不给标题，让孩子自己选这一步用哪个方法
- 错题再练一次
- 更多应用题：鸡兔同笼、年龄、分东西
- 讲解配上语音
- 画图法：两条直线的交点就是答案
