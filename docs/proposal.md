## 一、一句话说明

给 IB 四年级（9–10 岁）的孩子学**二元一次方程组**。用天平来讲：**每架平衡的天平就是一个方程，每种水果就是一个未知数**。一共 7 节课，每节课只学一个新方法。每道题都一步一步**演算**出来：先跟老师学例题，再照着例题自己演算。

| 项目 | 内容 |
|---|---|
| 名称 | 天平学方程 |
| 学生 | 9–10 岁，IB PYP 四年级；也适合刚接触方程的小学高年级学生 |
| 学完能做什么 | 会一步一步解两个未知数的方程组（代入、两式相减、两式相加），能看懂用 x、y 写的方程组 |
| 每次用多久 | 一节课 10–15 分钟 |
| 设备 | 平板、电脑或手机的浏览器；不用下载，不用登录 |
| 语言 | 默认中文，设置里可以换成 English |

## 二、演算纸：例题和练习用的是同一种写法

演算纸先写**题目**：每架天平的图和它的算式。然后一步一步往下写，前面的步骤一直留在纸上，孩子能看到每一步是从哪一行来的。例题的步骤是老师列的，练习的步骤是孩子自己列的，写出来的样子一模一样。每一步有四样东西：

1. **第几步 + 做什么**：比如“第 3 步　两式相减：A 减去 C”；
2. **为什么**：一句话讲道理（例题里写；练习时由孩子自己想）；
3. **这一步的天平**：就画在这一步里，先是变之前，再变成变之后，两边飘出这一步做的事（比如左边“− (🍎 + 🍌)”、右边“− 9”），点一下可以再看一次；
4. **数字步骤**：把算的过程一行一行写出来。

| 这一步做什么 | 数字步骤怎么写 |
|---|---|
| 两边同时 ÷ | 3🍎 ÷ 3 = 12 ÷ 3 → 🍎 = 4 |
| 两边同时 − | 2🍎 + 3 − 3 = 11 − 3 → 2🍎 = 8 |
| 代入 | 🍎 + 🍌 = 9 → 4 + 🍌 = 9（换掉的东西写在原来的位置上） |
| 两式相加、相减 | 竖式，上下对齐：左边加（减）左边，右边加（减）右边 |
| 把几份换掉 | 3x + 2y = 22 → x + (x + y) + (x + y) = 22 → x + 9 + 9 = 22 |

例：第 5 课的例题（A：2🍎 + 🍌 = 13，B：🍎 + 2🍌 = 14）

```
第 1 步  把 A 和 B 加起来
         两架平的天平放在一起，还是平的。上下对齐，左边加左边，右边加右边。
       A   2🍎 +  🍌 = 13
    +  B    🍎 + 2🍌 = 14
       ─────────────────
       C   3🍎 + 3🍌 = 27

第 2 步  C 的两边同时 ÷ 3
         C 的左边正好是 3 份（🍎 + 🍌）。两边同时平均分成 3 份，天平还是平的。
       C   (3🍎 + 3🍌) ÷ 3 = 27 ÷ 3
       C   🍎 + 🍌 = 9

第 3 步  A 减去 C
         A 和 C 都有 🍎 和 🍌，A 还多 1 个 🍎。上下对齐，左边减左边，右边减右边：
         一样的东西减掉了，剩下多出来的 1 个 🍎。
       A   2🍎 + 🍌 = 13
    −  C    🍎 + 🍌 = 9          （上下的 🍌 一样多，划掉）
       ─────────────────
       A    🍎      = 4

第 4 步  把 🍎 = 4 代入 C
         已经算出 🍎 = 4。把 C 里的 🍎 换成 4，天平还是平的。
       C   🍎 + 🍌 = 9
       C   4 + 🍌 = 9

第 5 步  C 的两边同时 − 4
         C 的左边除了 🍌，还有 4。两边同时拿走 4，天平还是平的。
       C   4 + 🍌 − 4 = 9 − 4
       C   🍌 = 5

答：🍎 = 4，🍌 = 5
检查：A 2 × 4 + 5 = 13 ✓　B 4 + 2 × 5 = 14 ✓
```

## 三、每节课怎么上

### 1. 例题（教）

1. 页面最上面写着：“📖 这是例题，跟着我一步一步学”，下面一句话讲这节课的方法。比如第 4 课：“两架天平比一比：一样的划掉，多出来的东西重多少，右边就多多少。算出一样，再换进天平，求另一样。”
2. 先看题目，再点“下一步”，一步一步往下看。每一步都按上面的四样东西写出来，天平就在这一步里变。
3. 算出来的数标成绿色，练习时孩子要自己填的就是这些数。
4. 最后写出答案，再把答案放回每架天平检查一遍。可以点“上一步”回看，也可以“再看一遍”；看懂了点“开始练习”。
5. **老师讲解的声音**：每翻一页，猫头鹰老师把这一页读出来。比如第 2 课第 1 步：“第 1 步：A 的两边同时减 3。A 的左边除了 2 个苹果，还有 3。两边同时拿走 3，天平还是平的。11 减 3 等于 8，所以 2 个苹果等于 8。”没听清可以点“🔊 再听一遍”；顶栏右上角的 🔊 可以关掉声音。

### 2. 练习（学）：孩子自己列步骤

一共 5 道题，和例题是同一类题，每次都是新出的题。页面最上面写着“✏️ 练习 1 / 5：自己列步骤，一步一步算”。演算纸上只有题目，**没有写好的步骤**，每一步都要孩子自己列：

1. **想：这一步做什么？** 从这一课学过的方法里选一个：
   - 第 1 课：两边同时 ÷
   - 第 2 课：再加上两边同时 −
   - 第 3 课：再加上代入
   - 第 4 课（试用看图算）：只有 ⚖️ 比一比、🔄 换一换
   - 第 7 课：两边同时 ÷、两边同时 −、代入、两式相减
   - 第 5、6 课：再加上两式相加
2. **点天平、写数**：点一架天平（两式相减、相加点两架），写上要 ÷ 或 − 的数。这一步写成一句话：“A 的两边同时 − ?”“把 🍎 = 5 代入 B”“A 减去 C”“把 A 和 B 加起来”。
3. **点“写出来”**，程序检查这一步能不能这样做：
   - **不能**：只说为什么，不替孩子选。比如：
     - “天平 A 的左边还有砝码 3。先把砝码拿走，再平均分。”
     - “天平 A 的左边是 3🍎，不能正好平均分成 2 份。”
     - “天平 B 的 🍌 比天平 A 多，A 减去 B 不够减。”
     - “还没有算出哪样东西等于几。先算出一样，才能代入。”
   - **能**：把这一步写进演算纸，“两边同时”的那一行也写出来，结果里变了的数空着，让孩子自己算：
     ```
     第 1 步  A 的两边同时 − 5
            A  2🍎 + 5 − 5 = 17 − 5
            A  2🍎 = ☐                 ← 孩子算：填 12
     ```
4. **算结果**：点空，用屏幕上的数字键盘填，键盘上方会显示正在填的那一行。算错了这个数变红，让孩子再算。都算对了：这一步打勾，这一步的天平跟着变，再列下一步。
5. 一直列到每样东西都算出来，最后写出答案，再把答案放回每架天平检查。

孩子走的路和例题不一样也可以，只要每一步都对。列错了方向，可以点“**↶ 擦掉一步**”，换一个方法。

**不会做的时候**，孩子可以自己选下面两种帮助，只有点了才出现，不会自己弹出来：
- 💡 **提示（步骤提示）**：写在孩子正在列步骤的地方，按孩子现在写到的样子给。
  - 第一次点：问下一步怎么想，不说方法。比如“看天平 A：左边除了 2 个 🍎，还有砝码 5。怎样让左边只剩下 2 个 🍎？”
  - 第二次点：说用哪个方法、哪架天平。比如“用「两边同时 −」：A 的两边同时 − 5。”
  - 算结果的时候点，只说这个数怎么算，比如“12 ÷ 3 = ?　想一想：3 × ? = 12”。
  - 提示都不说结果，数还是孩子自己算。
- 📖 **看例题**：打开例题的完整演算，每一步都写着为什么。

练习时，孩子点了“提示”、这一步不能这样做、算错了、做对了，老师都会把那句话读出来；列步骤、算数的时候不说话，让孩子自己想。

**成绩**：“5 道题里，一次做对几道”。没有列错步骤、没有算错、没看提示，才算一次做对。5 道都一次做对得 3 颗星，3–4 道得 2 颗星，其余 1 颗星。

## 四、7 节课

| 课 | 学什么 | 例题 | 关键的一步 | 课本里的名字 |
|---|---|---|---|---|
| 1 平均分 | 几个一样的东西一共多重，1 个有多重 | 3🍎 = 12 | A 的两边同时 ÷ 3：3🍎 ÷ 3 = 12 ÷ 3 | 等式两边同除以一个数 |
| 2 两边同时拿走 | 左边还有砝码时，先把它拿走 | 2🍎 + 3 = 11 | A 的两边同时 − 3：2🍎 + 3 − 3 = 11 − 3 | 等式两边同减一个数 |
| 3 先求一个，再代入 | 两种水果，先算出一种 | 2🍎 = 10，🍎 + 🍌 = 8 | 把 🍎 = 5 代入 B：5 + 🍌 = 8 | 代入消元法 |
| 4 比一比，换一换（看图算，试用） | 两架天平比一比，一样的划掉；知道一样，换进去求另一样 | 🍎 + 🍌 = 10，2🍎 + 🍌 = 14 | 比一比：14 − 10 = 4，所以 🍎 = 4；换一换：10 − 4 = 6 | 加减消元法（两式相减） |
| 5 两式相加 | 两个算式相加 | 2🍎 + 🍌 = 13，🍎 + 2🍌 = 14 | 把 A 和 B 加起来（竖式）：3🍎 + 3🍌 = 27 | 加减消元法（两式相加） |
| 6 用字母写方程组 | 把水果换成 x 和 y | x + y = 10，2x + y = 14 | 和前面一样，只是写成字母 | 二元一次方程组 |
| 7 买东西 | 用方程组算价钱 | 🍦 + 🧃 = 8 元，2🍦 + 🧃 = 13 元 | B 减去 A（竖式）：🍦 = 5 | 应用题 |

第 6 课的练习把前面几种题混在一起；第 7 课的练习是第 3、4 课的题型，换成了买东西。后面的课用的都是前面学过的方法，每节课只多学一个新东西。

## 五、为什么这样教

- **步骤就是方法**：每一步做什么由孩子自己决定。选错了方法，程序说清楚为什么不行（这正是方法的道理），孩子再自己换。
- **每一步都能推出下一步**：两边做了什么写成算式，相加、相减用竖式对齐，一样的东西划掉，孩子能看清新算式是怎么来的。
- **看得到前后关系**：前面的步骤一直留在同一张纸上，从题目一路写到答案。
- **图就在旁边**：天平画在正在看的这一步里，看算式的时候就能看到天平怎么变。
- **先学，再自己做**：例题写明“这是例题”，每一步说清楚为什么；练习时步骤的写法和例题一样，但步骤要孩子自己列，数也要孩子自己算。
- **提示帮孩子想，不替孩子做**：先问怎么想，再说用哪个方法；数还是孩子自己算。
- **从实物到符号**：天平上的水果 → 演算纸上的算式（2🍎 + 🍌 = 13）→ 第 6 课的 2x + y = 13。

## 六、题目怎么出

1. 先定答案：每样东西的重量是 2–9 的整数，两样东西不一样重。
2. 按本课的题型摆出天平，右边的数由答案算出来，所以答案一定是整数；右边的数不超过 60。
3. 用程序按本课的方法把题解一遍，确认只用这一课学过的方法就能解出来。
4. 同一组的 5 道题不重复，每次进来都是新题。

孩子列的每一步，程序都会检查：
- 这一步能不能这样做，不能就说为什么；
- 结果里要孩子算的数对不对；
- 提示按孩子现在写到的地方想下一步，孩子走的路和例题不一样也能接着提示。

自动测试（`npm test`）会检查每课的例题和 100 组随机题：
- 例题的每一行算式、孩子列出的每一步，把答案代进去都成立；
- 竖式里左边加（减）左边、右边加（减）右边都算对了；
- 一直照着提示列步骤，一定能做完，算出全部答案；
- 列错的步骤会说出正确的原因；
- 孩子换一条路做（比如先算出 🍌），提示也能接着带到答案。

## 七、和前面的版本相比，去掉了什么

- 侦探主题、案件和剧情；关卡地图和贴纸本。
- “分一分”“拿走”“换进来”“合起来”这些替孩子做的按钮。现在方法由老师在例题里演示，练习时孩子自己选方法、自己列步骤。
- 步骤列好、孩子只填空的练习（v1.1、v1.2）。
- 只说“这个空怎么填”的提示；现在的提示从“下一步做什么”入手。
- 整段的长句讲解；一步一页、看不到前面步骤的讲解方式。
- 只写结果、推不出下一步的步骤（比如只写“A 比 C 多 1 个 🍎 → 🍎 = 4”）。
- 放在左边、看算式时看不到的大天平。
- 只填最后答案的答案栏，以及“答错了天平会歪”的称一称。
- 自动弹出的提示。
- 鸡兔同笼一关（以后可以作为应用题再加回来）。

## 八、技术

| 项目 | 做法 |
|---|---|
| 框架 | Vue 3 + Vite，打包成一个独立的 HTML 文件（约 200 KB），双击也能打开 |
| 图形 | 手画的 SVG 天平，每一步变化时晃一晃再停稳；猫头鹰老师也是 SVG |
| 音效 | 用 Web Audio 现场合成，不需要音频文件，可以关掉 |
| 老师讲解的声音 | 用豆包语音合成大模型提前录成 mp3（`npm run voice`，API Key 只从环境变量读，不进网页）；网页按“声音 + 这句话”算出文件名找录音，没有录音的话用设备自带的朗读（speechSynthesis）；可以关掉 |
| 字体 | 数字和字母用内嵌的 Fredoka，中文用系统字体，不依赖外网 |
| 学习记录 | 只存在这台设备的浏览器里（localStorage），读写失败也不影响使用 |
| 测试 | Vitest：天平模型、解题程序、出题、讲解步骤、演算过程 |
| 发布 | 现在是 claude.ai 上的网页，打开链接就能用；以后可以合并到 `main`，自动发布到 GitHub Pages |

目录结构见 [README](../README.md)。

## 九、儿童友好与隐私

- 大按钮、大字号；用屏幕上的数字键盘填数，键盘上方显示正在填的那一行
- 对错同时用颜色和 ✓ 表示；系统开启“减少动态效果”时关闭动画
- 设置里有给家长的说明：每一课对应课本里的哪种方法
- 无广告、无外部链接；不用注册，不收集任何个人信息
