# 「天平学方程」儿童方程学习网页 · 方案

> 版本 v1.0 · 2026-09-28
>
> v1.0 是一次重新设计：从“方程小侦探”游戏改成**简单的学习方案**，重点放在“教”和“学”上。
> 去掉侦探主题、剧情、关卡地图、贴纸，以及“分一分”这类道具按钮。
> 每节课只有两部分：**先看讲解，再做 5 道练习**；每道练习只问一个问题：🍎 = ?

---

## 一、一句话说明

给 IB 四年级（9–10 岁）的孩子学**二元一次方程组**。用天平来讲：**每架平衡的天平就是一个方程，每种水果就是一个未知数**。一共 7 节课，每节课只学一个新方法。

| 项目 | 内容 |
|---|---|
| 名称 | 天平学方程 |
| 学生 | 9–10 岁，IB PYP 四年级；也适合刚接触方程的小学高年级学生 |
| 学完能做什么 | 会解两个未知数的方程组（代入、两式相减、两式相加），能看懂用 x、y 写的方程组 |
| 每次用多久 | 一节课 10–15 分钟 |
| 设备 | 平板、电脑或手机的浏览器；不用下载，不用登录 |
| 语言 | 默认中文，设置里可以换成 English |

## 二、每节课怎么上

每节课都一样，分两部分。

### 1. 讲解（教）

1. 猫头鹰老师先用一两句话说这节课的方法。例如第 1 课：“天平是平的，说明左右两边一样重。左边几个一样的东西一共重多少，除以个数，就是 1 个的重量。”
2. 然后讲一道例题，孩子点“下一步”，一步一步往下看。每一步：
   - 天平跟着变，两边同时飘出一样的“÷ 3”“− 3”，孩子能看到两边做的是同一件事，天平还是平的；
   - 下面用一句话写清楚这一步做了什么、算式是什么。例如：“天平 A：3 个 🍎 一共重 12。把两边都平均分成 3 份，1 个 🍎 重 12 ÷ 3 = 4。”
3. 最后一页写出答案，再把答案放回每架天平检查一遍（例如“3 × 4 = 12 ✓”）。
4. 可以点“上一步”回看，也可以“再看一遍”；看懂了点“开始练习”。

### 2. 练习（学）

- 一共 5 道题，和例题是同一类题，每次都是新出的题。
- **每道题只有一个问题**：🍎 = ?（有两种东西就是 🍎 = ?、🍌 = ?）。孩子看天平，自己想、自己算，在下面的格子里填数字，点“检查答案”。
- **答对了**：格子变绿，打 ✓，点“下一题”。
- **答错了**：不告诉答案，而是把孩子填的数放到天平上：天平会歪，并显示两边各有多重（例如“40 > 35”），孩子能看出哪边太重了。格子标 ✗，改好再检查。
- **不会做**：孩子可以自己选下面两种帮助。只有点了才出现，不会自己弹出来。
  - 💡 **提示**：只说第一步怎么想，不给答案。例如“天平 A 左边有 3 个 🍎，一共重 12。那 1 个 🍎 有多重？”再点一次，会建议去看讲解。
  - 📖 **看讲解**：这道题的完整解法，和例题一样一步一步看。看完回到题目，自己把答案填上。
- **成绩**：“5 道题里，第一次就答对几道”。没答错、没看提示、没看讲解，才算第一次答对。5 道都第一次答对得 3 颗星，3–4 道得 2 颗星，其余 1 颗星。之后可以“再练一次”（换一组新题），或者进入下一课。

## 三、7 节课

| 课 | 学什么 | 例题 | 讲解里最关键的一步 | 课本里的名字 |
|---|---|---|---|---|
| 1 平均分 | 几个一样的东西一共多重，1 个有多重 | 3🍎 = 12 | 两边平均分成 3 份：12 ÷ 3 = 4 | 等式两边同除以一个数 |
| 2 两边同时拿走 | 左边还有砝码时，先把它拿走 | 2🍎 + 3 = 11 | 两边拿走 3：11 − 3 = 8；再 8 ÷ 2 = 4 | 等式两边同减一个数 |
| 3 先求一个，再代入 | 两种水果，先算出一种 | 2🍎 = 10，🍎 + 🍌 = 8 | 🍎 = 5，放进另一架：🍌 + 5 = 8 | 代入消元法 |
| 4 两式相减 | 两架天平比一比 | 🍎 + 🍌 = 10，2🍎 + 🍌 = 14 | B 比 A 多 1 个 🍎，也重了 14 − 10 = 4 | 加减消元法（两式相减） |
| 5 两式相加 | 没法直接比时，把两架合起来 | 2🍎 + 🍌 = 13，🍎 + 2🍌 = 14 | 合起来 3🍎 + 3🍌 = 27，平均分得 🍎 + 🍌 = 9 | 加减消元法（两式相加） |
| 6 用字母写方程组 | 把水果换成 x 和 y | x + y = 10，2x + y = 14 | 和前面一样，只是写成字母 | 二元一次方程组 |
| 7 买东西 | 用方程组算价钱 | 🍦 + 🧃 = 8 元，2🍦 + 🧃 = 13 元 | B 比 A 多 1 个 🍦，贵了 13 − 8 = 5 元 | 应用题 |

第 6 课的练习把前面几种题混在一起；第 7 课的练习是第 3、4 课的题型，换成了买东西。

**举例：第 5 课例题的完整讲解**

2🍎 + 🍌 = 13，🍎 + 2🍌 = 14

1. 把天平 A 和天平 B 合起来：左边的东西放在一起，右边加起来是 13 + 14 = 27。合起来的天平 C 是 3🍎 + 3🍌 = 27。
2. 天平 C：3 份（🍎 + 🍌）一共重 27。把两边都平均分成 3 份，1 份（🍎 + 🍌）重 27 ÷ 3 = 9。
3. 比一比天平 C 和天平 A：A 比 C 多了 1 个 🍎，也重了 13 − 9 = 4。所以 🍎 = 4。
4. 已经知道 🍎 = 4。把天平 C 上的 🍎 换成 4，天平 C 就变成 🍌 + 4 = 9。
5. 天平 C 两边同时拿走 4，天平还是平的。左边只剩 🍌，所以 🍌 = 9 − 4 = 5。

最后：所以 🍎 = 4，🍌 = 5。检查：2 × 4 + 5 = 13 ✓，4 + 2 × 5 = 14 ✓。

可以看到，后面的课用的都是前面学过的方法（平均分、比一比、代入、拿走），每节课只多学一个新东西。

## 四、为什么这样教

- **一次只学一个方法**：每节课一个新方法，例题和练习是同一类题。
- **先看，再做**：方法由老师在讲解里演示；练习时孩子只需要回答“🍎 = ?”，不用先学怎么操作界面。
- **从实物到符号**：天平上的水果 → 天平下面的算式（2🍎 + 🍌 = 13）→ 第 6 课的 2x + y = 13。
- **错了自己看出来**：答错时不给答案，把孩子的数放上天平。天平歪了，孩子自己看出是大了还是小了。
- **帮助由孩子自己选**：提示只说第一步的想法，完整步骤在“看讲解”里；都不会自己弹出来。

## 五、题目怎么出

1. 先定答案：每样东西的重量是 2–9 的整数，两样东西不一样重。
2. 按本课的题型摆出天平，右边的数由答案算出来，所以答案一定是整数；右边的数不超过 60。
3. 用程序按本课的方法把题解一遍，确认能解出来。练习里“看讲解”的步骤也是这样一步一步生成的，所以每道题都有自己的完整讲解。
4. 同一组的 5 道题不重复，每次进来都是新题。

自动测试（`npm test`）会检查每课的例题和 100 道随机题：讲解每一步的算式都对，最后得出的答案正确，而且用到了这节课要学的方法。

## 六、和上一版相比，去掉了什么

- 侦探主题、案件和剧情；关卡地图和贴纸本。
- “分一分”“拿走”“换进来”“合起来”这些按钮。这些方法现在放在讲解里由老师演示；练习只问 🍎 = ?，不再把一道题拆成两部分。
- 自动弹出的提示。
- 鸡兔同笼一关（以后可以作为应用题再加回来）。

## 七、技术

| 项目 | 做法 |
|---|---|
| 框架 | Vue 3 + Vite，打包成一个独立的 HTML 文件（约 200 KB），双击也能打开 |
| 图形 | 手画的 SVG 天平，会按两边的重量倾斜；猫头鹰老师也是 SVG |
| 声音 | 用 Web Audio 现场合成，不需要音频文件，可以关掉 |
| 字体 | 数字和字母用内嵌的 Fredoka，中文用系统字体，不依赖外网 |
| 学习记录 | 只存在这台设备的浏览器里（localStorage），读写失败也不影响使用 |
| 测试 | Vitest：天平模型、解题程序、出题、每课的讲解 |
| 发布 | 现在是 claude.ai 上的网页，打开链接就能用；以后可以合并到 `main`，自动发布到 GitHub Pages |

目录结构见 [README](../README.md)。

## 八、儿童友好与隐私

- 大按钮、大字号；用屏幕上的数字键盘填答案，不会挡住题目
- 对错同时用颜色和 ✓ / ✗ 表示；系统开启“减少动态效果”时关闭动画
- 设置里有给家长的说明：每一课对应课本里的哪种方法
- 无广告、无外部链接；不用注册，不收集任何个人信息

## 九、以后可以加

- 根据孩子用下来的情况调整难度
- 错题再练一次
- 更多应用题：鸡兔同笼、年龄、分东西
- 讲解配上语音
- 画图法：两条直线的交点就是答案
