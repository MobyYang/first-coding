# 「方程小侦探」儿童方程学习网页应用 · 方案

> 版本 v0.1 · 2026-09-28

> **关于题目的理解**：需求里的“一双一次方程”，这里理解为**二元一次方程组**（两个未知数、两个方程，如 `x + y = 10`，`x − y = 2`）。
> 学它之前要先会**一元一次方程**，而解二元一次方程组的核心“消元”，本质上就是把它变回一元一次方程。所以本方案按「一元 → 二元」循序渐进。如果只需要一元一次方程，保留第 1、2 章即可。

---

## 一、产品定位

| 项目 | 内容 |
|---|---|
| 名称（暂定） | **方程小侦探**：未知数是“藏起来的数”，每个方程是一条“线索” |
| 目标用户 | 10–13 岁、刚开始接触方程的孩子（小学高年级 ~ 初一） |
| 使用场景 | 在家用平板或电脑自学、课后巩固，每次 10–20 分钟 |
| 次要用户 | 家长 / 老师：看学习报告、打印练习卷 |
| 核心目标 | 让孩子**理解**方程为什么能这样解，而不只是背步骤 |
| 成本 | 纯静态网页，托管免费，不需要服务器 |

“侦探”主题和二元方程组天然契合：只有一条线索（`x + y = 10`）时，符合条件的“嫌疑人”太多，破不了案；再来一条线索（`x − y = 2`），答案才被唯一锁定。孩子由此自然明白“为什么需要两个方程”。

## 二、教学设计

### 2.1 三步走：实物 → 图形 → 符号

参考新加坡数学的 CPA 教学法（Concrete–Pictorial–Abstract）和 DragonBox 等经典代数游戏的思路：每个新概念都先“摸得着”，再“看得见”，最后才用字母。

| 阶段 | 表现形式 | 例子 |
|---|---|---|
| 实物 | 天平 + 神秘盒子，可以拖动砝码 | 左盘：🎁 和 3 个砝码；右盘：7 个砝码 |
| 图形 | 水果、动物图标组成的算式 | 🍎 + 🍎 + 🍌 = 16 |
| 符号 | 字母方程 | 2x + y = 16 |

### 2.2 核心比喻：方程就是一架平衡的天平

- **等式性质 1**：两边同时加上（或减去）同一个数，天平仍然平衡。
- **等式性质 2**：两边同时乘（或除以）同一个不为 0 的数，天平仍然平衡。
- **只动一边，天平马上倾斜**：把错误“画”出来，比打一个 ✗ 更直观。
- **代入消元 = 等量替换**：已知 🍌 和“🍎 + 1”一样重，就可以把天平上的每根 🍌 都换成“🍎 + 1”。
- **加减消元 = 从天平上拿走一样重的东西**：

```
天平甲：🍎🍎 + 🍌🍌🍌🍌  ⚖  14     （2x + 4y = 14）
天平乙：🍎🍎 + 🍌🍌🍌    ⚖  12     （2x + 3y = 12）
```

天平乙是平衡的，说明“2 个苹果 + 3 根香蕉”和“12”一样重。从天平甲的左边拿走“2 个苹果 + 3 根香蕉”，右边拿走 12，天平甲仍然平衡，只剩下 🍌 ⚖ 2，也就是 y = 2。

### 2.3 设计原则

1. **先操作，后书写**：一开始孩子只需“选操作 + 选数字”，由 App 算出新方程；随后逐步撤掉辅助，最后自己写出每一步。
2. **反馈要具体**：不只说“错了”，而是指出错在哪里（见 5.3「常见错误诊断」）。
3. **三级提示**：思路方向 → 具体下一步 → 完整示范（示范后再给一道同类题）。
4. **关卡要短**：每关 5–8 题、3–5 分钟，做完马上有奖励。
5. **难度自适应**：连对 3 题升一档；连错 2 题降一档，并主动给提示。
6. **间隔复习**：错题进入错题本，按 1 天、3 天、7 天的间隔，用“换了数字的同类题”复习。

## 三、课程与关卡

地图上每一章是一座小岛，每关可得 1–3 颗星。

### 第 1 章 · 天平与神秘盒子（等式的性质）

| 关卡 | 内容 | 例题 |
|---|---|---|
| 1-1 | 平衡还是不平衡？认识等式 | 3 + 4 和 5 + 2 放上天平，平衡吗？ |
| 1-2 | 两边拿走一样多 | 🎁 + 3 = 7 |
| 1-3 | 平均分 | 🎁🎁🎁 = 12 |
| 1-4 | 两步操作 | 🎁🎁 + 3 = 11 |

### 第 2 章 · 字母 x 登场（一元一次方程）

| 关卡 | 内容 | 例题 |
|---|---|---|
| 2-1 | 用 x 代替盒子 | x + 5 = 12，3x = 18 |
| 2-2 | 两步方程 | 2x + 3 = 11，5x − 4 = 21 |
| 2-3 | 两边都有 x（移项） | 5x + 2 = 3x + 10 |
| 2-4 | 去括号 | 2(x + 3) = 14 |
| 2-5 ★ | 负数（拓展，默认关闭） | 3 − 2x = 7 |

### 第 3 章 · 两个神秘数（认识二元一次方程）

| 关卡 | 内容 | 例题 |
|---|---|---|
| 3-1 | 水果谜题：先解出一个，再代进去 | 🍎 + 🍎 = 10，🍎 + 🍌 = 8，🍌 = ? |
| 3-2 | 一条线索不够 | “两个数的和是 10”：找出所有可能，发现答案不止一组 |
| 3-3 | 两条线索破案 | 再加一条“两数之差是 2”，两张表里共同的那一组就是答案 |

3-1 其实已经在用代入法了，只是孩子还不知道这个名字。

### 第 4 章 · 消元大法（解二元一次方程组）

| 关卡 | 内容 | 例题 |
|---|---|---|
| 4-1 | 代入消元 | y = x + 1，x + y = 7 |
| 4-2 | 加减消元：直接加减 | x + y = 10，x − y = 2 |
| 4-3 | 加减消元：先把一个方程乘几倍 | 2x + 3y = 12，x + 2y = 7 |
| 4-4 | 加减消元：两个方程都要乘 | 3x + 2y = 16，2x + 3y = 14 |
| 4-5 ★ | 自选方法 + 检验 | 自己决定用代入还是加减 |

### 第 5 章 · 生活中的方程（应用题）

| 关卡 | 内容 | 例题 |
|---|---|---|
| 5-1 | 鸡兔同笼（出自《孙子算经》） | 35 个头、94 只脚，鸡兔各几只？ |
| 5-2 | 购物问题 | 2 支笔 + 3 个本子 = 19 元，1 支笔 + 2 个本子 = 12 元 |
| 5-3 | 年龄问题 | 爸爸比小明大 28 岁，爸爸的年龄是小明的 5 倍 |

应用题统一用“侦探五步法”引导：**找未知数 → 设 x、y → 找两条等量关系（线索）→ 列方程组并求解 → 检验答案是否合理**（比如鸡的只数不能是负数或小数）。

鸡兔同笼还会用动画演示古人的“抬腿法”，再和方程法对比，让孩子体会方程这种方法有多通用。

### 第 6 章 · 画图找答案（拓展）

| 关卡 | 内容 |
|---|---|
| 6-1 | 把 x + y = 10 的整数解画成点，发现它们排成一条直线 |
| 6-2 | 两条直线的交点，就是方程组的解 |
| 6-3 | 两线平行 → 无解；两线重合 → 无数组解 |

### 贯穿全程

- 🗺️ **闯关地图**：拿到星星解锁下一关
- 📅 **每日挑战**：每天 5 题，用日期作随机种子，全家同一天做的是同一套题，可以比一比
- 📕 **错题本**：自动收集，一键“再练一道同类题”
- 🏅 **徽章**：天平平衡师、移项小能手、消元大师、鸡兔专家、连对 10 题……

### 一次学习的流程

1. 打开地图，点击已解锁的关卡
2. 吉祥物（戴侦探帽的小猫头鹰）用 30 秒演示一道例题
3. 做 5–8 题：前两题辅助较多，后面逐步撤掉
4. 结算：星星 + 鼓励语，错题自动进入错题本
5. 解锁下一关；每天第一次打开时，先做 3 道复习题

## 四、核心交互组件

### 4.1 天平（第 1 章主角）

- 用 SVG 绘制，左右托盘里放“神秘盒子 🎁”和砝码。
- 操作按钮：两边同时**拿走** n 个砝码 / **放上** n 个砝码 / **平均分成** n 份。
- “自由模式”允许只动一边：天平随之倾斜，并提示“天平歪啦，另一边也要一样哦”。
- 倾斜角度 = 两边重量差 × 系数（设上限），配缓动动画。
- 负数用“气球”表示（气球向上拉，相当于减轻重量），弥补天平表示不了负数的短板。

### 4.2 分步解题器（第 2、4 章主角）

```
←返回      第 2 章 · 第 2 关       ⭐⭐☆      3 / 8
────────────────────────────────────────────
【小天平动画，随方程同步变化】

          2x + 3 = 11
   ↓ 两边同时 −3
              2x = 8
   ↓ 两边同时 ÷2
               x = 4     ✅ 破案！

下一步怎么做？
[两边 +]   [两边 −]   [两边 ×]   [两边 ÷]
[1] [2] [3] [4] [5] [6] [7] [8] [9] [0]     ← 屏幕数字键盘
💡 提示      🔊 读题
```

辅助分三个阶段逐步撤除：

| 阶段 | 孩子做什么 | App 做什么 |
|---|---|---|
| A 选操作 | 选“两边同时 −3” | 自动算出新方程 |
| B 填结果 | 选操作后，自己填出新方程 | 判断填得对不对 |
| C 自己写 | 直接写出每一步 | 判断每一步是不是“等价变形” |

二元方程组版本的操作换成「① × k」「② × k」「① + ②」「① − ②」「代入」，最后回代并检验：

```
① 2x + 3y = 12
② x + 2y = 7

② × 2           →  ③ 2x + 4y = 14
③ − ①           →  y = 2
把 y = 2 代入 ②  →  x + 4 = 7  →  x = 3
检验：2×3 + 3×2 = 12 ✓     3 + 2×2 = 7 ✓
```

## 五、出题与判题（技术核心）

### 5.1 先定答案，再出题

所有题目都**先随机选好答案，再反推出题目**，保证答案一定是整数、数字大小适合孩子：

```js
// 生成 ax + b = c，答案 x 是 1~10 的整数
function makeTwoStep(rng) {
  const x = rng.int(1, 10);   // 1. 先定答案
  const a = rng.int(2, 9);    // 2. 随机选系数
  const b = rng.int(1, 20);
  const c = a * x + b;        // 3. 反推右边的数
  return { text: `${a}x + ${b} = ${c}`, answer: { x } };
}

// 生成二元一次方程组，答案 (x, y) 都是整数
function makeSystem(rng, level) {
  const x = rng.int(1, 10);
  const y = rng.int(1, 10);
  let a1, b1, a2, b2;
  do {
    [a1, b1, a2, b2] = pickCoefficients(rng, level); // 按难度挑系数
  } while (a1 * b2 === a2 * b1); // 排除“两条线索其实是同一条”的情况，保证有唯一解
  return {
    equations: [[a1, b1, a1 * x + b1 * y], [a2, b2, a2 * x + b2 * y]],
    answer: { x, y },
  };
}
```

二元方程组按系数规律分难度：

| 难度 | 系数规律 | 例子 |
|---|---|---|
| 代入入门 | 有一个方程形如 y = x + k 或 y = kx | y = x + 1，x + y = 7 |
| 加减入门 | 某个未知数的系数相同或相反 | x + y = 10，x − y = 2 |
| 加减进阶 | 一个系数是另一个的整数倍 | 2x + 3y = 12，x + 2y = 7 |
| 加减高级 | 两个方程都要乘 | 3x + 2y = 16，2x + 3y = 14 |

其他规则：

- **小学模式**：题目里的数，以及推荐解法每一步的结果，都是不超过 100 的正整数（可以有减号，但不出现负数）；初一模式才允许出现负数。
- **不重复**：同一关内不出重复的题。
- **可复现**：随机数可以设“种子”，同一个种子出同一套题（用于每日挑战、打印练习卷）。
- **应用题 = 模板 + 参数**：例如鸡兔同笼，先随机定下“鸡 23 只、兔 12 只”，再算出“35 个头、94 只脚”填进题目模板。

### 5.2 方程引擎

- 用**分数**表示所有系数，避免小数误差（比如 0.1 + 0.2 ≠ 0.3）。
- 方程表示为“左边 = 右边”，每一边是 { x 的系数，y 的系数，常数 }。
- 支持：两边同加 / 减 / 乘 / 除（除以 0 会被拦下并友好提示）、方程相加减、代入、检验。
- **判断一步写得对不对**：等价变形不会改变方程的解，所以检查孩子写出的新方程和上一步是否同解。
- **输入解析**：只需要支持一次式（如 `3x+2=5x-4`、`2(x+3)=14`），写一个小解析器即可，不必引入大型数学库；兼容中文输入法打出的全角符号（＋ － ＝ （ ））以及 ×、÷。

### 5.3 常见错误诊断

每类常见错误写成一条“错误规则”：先算出“犯这种错会得到的答案”，再和孩子的答案比对，命中就给出对应的提示；都没命中，再给通用提示。

| 错误类型 | 孩子的写法 | App 的反馈 |
|---|---|---|
| 只动了一边 | x + 3 = 7 → x = 7 | 天平歪啦！左边拿走了 3，右边也要拿走 3 |
| 移项忘了变号 | x + 3 = 7 → x = 7 + 3 | +3 从左边搬到右边，要变成 −3 |
| 乘除搞反 | 3x = 12 → x = 36 | 3x 是 3 个 x，要平均分成 3 份，应该 ÷3 |
| 把 3x 当成 3 + x | 3x = 12 → x = 9 | 3x 是 3 × x，不是 3 + x 哦 |
| 括号没乘全 | 2(x + 3) = 14 → 2x + 3 = 14 | 括号外的 2 要和括号里的每一项相乘 |
| 方程乘倍数时漏乘 | x + 2y = 7 两边 ×2 → 2x + 4y = 7 | 右边的 7 也要 ×2，天平两边要一起变成 2 倍 |
| 减法符号出错 | (x + y) − (x − y) 算成 0 | 减去 −y 等于加上 y，结果是 2y |
| 只求出一个就停 | 算出 y = 2 就提交 | 还差一个！把 y = 2 代回去求 x |

## 六、家长 / 老师功能

- **学习报告**：各章正确率、学习时长、最常犯的错误类型、建议复习的内容。
- **打印练习卷**：按关卡和难度一键生成 A4 练习卷（附答案页），用浏览器直接打印。
- **给家长的话**：每章附一小段说明：这一章学什么、孩子常卡在哪、在家怎么引导。
- **设置**：年级（决定是否出现负数）、数字范围、每日学习时长上限。
- **家长密码**：家长区用 4 位密码进入，防止孩子随手改设置。

## 七、儿童友好与隐私

- 大字号（正文 ≥ 20px）、大按钮（≥ 48px），手指点得准
- 对错不只靠红 / 绿区分，同时配 ✓ / ✗ 图标，照顾色弱的孩子
- 动画、音效、语音都可以单独关闭
- 连续学习 20 分钟，提醒休息眼睛
- **无需注册、不收集任何个人信息**：进度只保存在本机浏览器，昵称和头像自己随便起；无广告、无外部链接

## 八、技术方案

| 层面 | 选择 | 理由 |
|---|---|---|
| 框架 | Vue 3 + Vite | 组件化，适合天平、关卡这类交互；中文文档完善，对新手友好 |
| 语言 | JavaScript | 降低入门门槛 |
| 路由 | Vue Router（hash 模式） | 部署在 GitHub Pages 上，刷新页面不会 404 |
| 数据保存 | localStorage（带版本号） | 进度存在本机，不需要服务器 |
| 图形动画 | SVG + CSS 过渡 | 轻量，任何屏幕上缩放都清晰 |
| 公式排版 | KaTeX | 方程组的大括号、分数都能正确显示 |
| 语音 | Web Speech API | 浏览器自带，零成本 |
| 测试 | Vitest（出题、判题逻辑）+ Playwright（关键页面流程） | 自动检查“题目一定有整数解”“判题不出错” |
| 部署 | GitHub Pages + GitHub Actions | 免费；推送代码后自动上线 |
| 离线（第 4 阶段） | PWA | 可以添加到平板桌面，没网也能练 |

注意：

- 免费账户使用 GitHub Pages，要求仓库是公开的；首次需要在仓库 Settings → Pages 里把来源设为 GitHub Actions。
- GitHub Pages 在国内访问有时较慢。如果主要面向国内用户，同一份打包文件也可以部署到国内的静态托管服务（需要自有域名并完成备案）。

## 九、开发计划

| 阶段 | 内容 | 完成后 |
|---|---|---|
| 第 1 阶段 · MVP | 搭项目；方程引擎 + 出题器 + 单元测试；天平；一元分步解题器；一元常见错误提示；第 1–2 章；本地进度；自动部署 | 孩子可以在线从天平一路玩到移项、去括号 |
| 第 2 阶段 | 水果谜题、线索表格、二元分步解题器（代入 / 加减）；第 3–4 章；错题本；二元错误诊断 | 学会解二元一次方程组 |
| 第 3 阶段 | 第 5 章应用题（含鸡兔同笼动画）；闯关地图、星星、徽章；每日挑战；语音读题；家长报告；打印练习卷 | 成为一个完整的学习产品 |
| 第 4 阶段（可选） | 第 6 章图像法；PWA 离线；进度导出 / 导入或云同步 | 锦上添花 |

**验收标准**

- 出题器：自动随机生成 1 万道题，100% 有唯一整数解，数字都在设定范围内
- 找 1–2 个目标年龄的孩子试玩：不看说明，能独立完成第 1 关
- iPad、安卓平板、手机、电脑浏览器上都能正常操作
- 每关 3–5 分钟可以完成

## 十、风险与应对

| 风险 | 应对 |
|---|---|
| 孩子觉得无聊，坚持不下去 | 关卡短、奖励及时、侦探故事线、每日挑战 |
| 只会点按钮，自己不会写 | 辅助分三个阶段逐步撤掉（选操作 → 填结果 → 自己写） |
| 乱猜答案刷星星 | 以填空为主、少用选择题；连续答错时放慢节奏并给提示 |
| 天平表示不了负数 | 小学模式默认不出负数；拓展关用“气球”表示负数 |
| 进度只存在本机，换设备会丢 | 第 4 阶段提供进度导出 / 导入或云同步 |
| 国内访问 GitHub Pages 较慢 | 同一份静态文件可以换到国内的静态托管 |
